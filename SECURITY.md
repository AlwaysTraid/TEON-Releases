# Reporting a security issue

If you find a compromised release, a credential leak, an unexpected download, or a problem with TEON's game verification, contact Traid privately before opening a public issue. Include the TEON version, the release ZIP's SHA-256, and the steps needed to reproduce the problem. Do not send a Pokémon ROM, save file, private key, or an unredacted personal path.

Official releases are attached to this repository's GitHub Releases page. Verify the release asset against the SHA-256 published with that release before sharing it further.
